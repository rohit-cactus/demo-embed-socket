HOW IT WORKS
═════════════════════════════════════════════════════════════════════════════

  Multiple Browsers
        ↓
  Socket.IO WebSocket Connection (Port 3001)
        ↓
  Express Server (Handles events)
        ↓
  JSON File Storage (server/data/persistence.json)
        ↓
  Auto-Backups (server/data/backups/)

  Real-Time Flow:
  - Browser 1 adds comment
  - Emits 'createThread' event to Socket.IO
  - Server receives and broadcasts to all connected clients
  - Browser 2 receives and updates UI instantly
  - Server saves to persistence.json
